设计说明

MCP 接入 · 2026-10

按接入顺序排布

地址、Token、客户端、自检、工具清单依次推进，前一步的结果直接成为下一步的输入。弹层内部不再造左侧步骤条，避免在单一任务里叠加第二层导航。

信息密度取舍

地址与认证压成三行键值，解释文字留在 11–12px 的次级灰；工具清单用两列八行表格换取竖向空间。代码块独占整行，保证可以直接粘贴。

状态与颜色

一次性明文只出现一次，保存后只保留前缀；自检失败按 401 / 403 / 503 各给一个动作。青绿只用于主操作与成功图标，红与琥珀只出现在错误文字上。

MCP · Streamable HTTP

连接 Agent

创建 Token、复制客户端配置，并在保存前完成一次连接自检。所有配置只写入你自己的 AI 编码客户端。

01

接入地址

/mcp 是唯一入口
MCP 端点 https://youzhao.florai.cn/mcp
传输 Streamable HTTP
认证 Authorization: Bearer <Token>

/mcp/、/sse 及任何子路径都不会命中，请原样使用上方地址。客户端只支持远程 MCP 时，优先选 Streamable HTTP。

02

创建 Token

明文仅显示一次

用于区分客户端，例如「Claude Code · 本机」「CI 发布机」。

请输入 Token 名称。

能力（scope）

至少选择一项能力。

publish 不隐含 read，通常两项一起勾选；Token 能力取账号权限与 scope 的交集。

有效期

请选择过期日期。

创建后可复制配置，并立即检测连接。

权限与安全

  • read:blueprint 读取分组、蓝图与产物。
  • publish:blueprint 发布、覆盖与删除版本。
  • 两项独立授权；发布不包含读取。撤销立即生效，绑定账号被移出空间后 Token 同步失效。

结果说明

失败时只改一处，再重试。

401
Token 无效

确认 Token 完整、未被撤销，且 Bearer 后保留一个空格。

403
权限不足

Token 缺少 scope，或账号已离开空间。补齐能力后重新创建。

503
服务不可用

服务正在发布或触发限流。30 秒后重试，持续失败联系空间管理员。
