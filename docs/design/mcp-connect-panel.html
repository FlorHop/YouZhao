MCP 客户端接入（现状）

今天的说明让用户把仓库克隆到本机、再用 node 跑 server/mcp-server.mjs，并且地址写的是 http://127.0.0.1:4174（旧站端口）。云端用户照做会失败。

{"mcpServers":{"youzhao":{"command":"node","args":["/absolute/path/to/youzhao/server/mcp-server.mjs"],"env":{"YOUZHAO_API_BASE":"http://127.0.0.1:4174","YOUZHAO_MCP_TOKEN":"<创建 Token 时复制的明文>"}}}}

连接 Agent

接入地址https://youzhao.florai.cn/mcp 复制
认证Authorization: Bearer <Token>
协议Streamable HTTP；客户端协商协议版本，服务端同时支持新旧两代

地址由服务端下发（GET /api/mcp/connection-info），所以页面里不再出现 127.0.0.1。

{

      "command": "npx",
      "args": [
        "-y", "mcp-remote",
        "https://youzhao.florai.cn/mcp",
        "--header", "Authorization: Bearer <你的 Token>"
      ]
    }
  }
}
  1. 打开 Claude Desktop → Settings → Developer → Edit Config。
  2. 把上面的 JSON 合并进 claude_desktop_config.json，保存后重启 Claude Desktop。
  3. 需要本机已装 Node.js（npx 会临时拉取 mcp-remote，无需克隆仓库）。
